# Mrunal Birthday Website 🎂

A photo-free interactive birthday website built with plain HTML, CSS and JavaScript.

## GitHub Pages
1. Create a GitHub repository named `mrunal-birthday`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be available at:
   `https://YOUR-USERNAME.github.io/mrunal-birthday/`

No backend is required.
